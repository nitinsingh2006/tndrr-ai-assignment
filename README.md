## ▶️ Running Each Task

### Task 1: LoRA Fine-tuning

```bash
cd task1_lora
pip install -r requirements.txt

# Step 1: Generate dataset (CPU, runs in ~10 seconds)
python generate_dataset.py
# → creates data/train.jsonl (1000 examples) and data/test.jsonl (100 examples)

# Step 2: Fine-tune (needs GPU — use Colab or local GPU)
# Option A: Colab (recommended for most people)
#   Upload colab_notebook.ipynb to Google Colab, select T4 GPU runtime, Run All
# Option B: Local GPU (≥ 8GB VRAM recommended)
python train.py
# → saves model to lora_model/

# Step 3: Evaluate
python evaluate.py
# → saves results.json with valid_json_rate, exact_match, per_field_accuracy
```

**⚠️ RUN THIS on Colab:** Open `colab_notebook.ipynb` on Google Colab (T4 GPU). The notebook does Steps 1-3 end to end and downloads `results.json`.

### Task 2: RAG Pipeline

```bash
cd task2_rag
pip install -r requirements.txt

# Step 1: Download document
python download_doc.py
# → downloads ~5 MB survey PDF to data/survey_llm.pdf

# Step 2: Run RAG pipeline + evaluation
python rag_pipeline.py
# → extracts text, builds FAISS index, evaluates 15 questions
# → saves results.json with Recall@1, Recall@5, MRR for 2 chunk sizes + BM25 hybrid
```

> **Note:** Set `OPENAI_API_KEY` env var to also get LLM-generated answers. Otherwise retrieval-only evaluation runs fine.

### Task 3: Local LLM Benchmark

```bash
cd task3_local_llm
pip install -r requirements.txt

# Step 1: Download GGUF models (~500MB total)
python download_models.py
# → models/qwen2.5-0.5b-q4_k_m.gguf
# → models/qwen2.5-0.5b-q8_0.gguf

# Step 2: Run benchmark
python benchmark.py
# → results.json (tokens/sec, RAM, file size)
# → outputs.md (side-by-side quality comparison)
```

### Generate Report

```bash
# From repo root (after all tasks have run and results.json files are filled)
pip install -r requirements_root.txt
python generate_report.py
# → report.pdf (≤ 4 pages)
```

## 🎯 Design Decisions

1. **Model (Task 1):** SmolLM2-360M-Instruct chosen over Qwen2.5-0.5B for smaller footprint and fast Colab training. Task is simple (4-field JSON), so 360M params is sufficient.
2. **RAG document:** "A Survey of Large Language Models" (arXiv:2307.06435) — public, 100+ pages, rich content, varied information density.
3. **Task 3 framework:** `llama-cpp-python` chosen over Ollama (not installed) for direct Python control and reproducible benchmarking.
4. **Chunk sizes (Task 2):** 200 and 500 tokens tested. 200 gives more precise retrieval; 500 gives more context per chunk.
5. **No external frameworks (Task 2):** Strict requirement — only NumPy, FAISS, and sentence-transformers.
